# LumiBox

LumiBox — трехмерная воксельная песочница с физическим движком для веб-браузеров, объединяющая механики воксельного строительства, процедурной генерации ландшафта, симуляции физики твердых тел, динамической смены времени суток и погодных условий, а также встроенную среду разработки контента LumiBench Studio.

## Основные функциональные возможности

* **Процедурная генерация мира**: бесконечный ландшафт на основе многооктавного шума Симплекса, генерация биомов (равнины, леса, пустыни), подземных пещер, деревьев и природных структур.
* **Оптимизированный воксельный рендеринг**: разбиение мира на чанки 16x16x64, генерация сетки только для видимых граней (face culling), расчет мягкого затенения углов (Ambient Occlusion) и динамический текстурный атлас.
* **Физика вокселей и динамических тел**:
  * Дискретное разрешение столкновений AABB-коллайдеров с воксельной сеткой.
  * Падающие блоки (песок, гравий).
  * Водная среда с выталкивающей силой и гидродинамическим сопротивлением.
  * Трехмерные выпадающие предметы (`ItemDrop`) с физикой падения, вращением и автоподбором.
* **Сущности и искусственный интеллект**: система мобов с конечно-автоматным поведением (блуждание, преследование игрока, получение урона, анимация шага и атаки).
* **Игровые режимы и механики**:
  * Режимы выживания (Survival) с получением урона, расходом здоровья и сбором ресурсов и творчества (Creative) со свободным полетом.
  * Крафт предметов в сетке инвентаря (2x2) и на верстаке (3x3).
  * Плавка руды в печи с учетом коэффициента теплотворности топлива.
* **Окружающая среда и атмосфера**:
  * Цикл дня и ночи с динамическим перемещением солнца, луны и звездной полусферы.
  * Погодные осадки (дождь, снегопад) с частицами и изменением освещения.
* **LumiBench Studio**: интегрированный веб-инструмент для создания 3D-моделей воксельных блоков, попиксельного рисования текстур и экспорта пакетов модификаций в формате `.lumibench` / `.zip`.
* **Модульная архитектура**: загрузка внешних пакетов текстур и модулей контента без перезапуска игры.
* **Сохранение состояния**: сериализация и десериализация измененных блоков, положения игрока и инвентаря в LocalStorage с поддержкой множества миров.
* **Кроссплатформенное управление**: поддержка клавиатуры и мыши (Pointer Lock API) на ПК, а также виртуального экранного стика и сенсорных зон на мобильных устройствах.

## Локальный запуск

Так как проект использует ECMAScript-модули и загружает текстурные атласы и манифесты через `fetch`, запуск напрямую через протокол `file://` блокируется политикой безопасности браузера (CORS). Требуется любой локальный HTTP-сервер.

### Способ 1. Использование Node.js (`npx serve`)
```powershell
npx serve .
```
После запуска перейдите по адресу `http://localhost:3000`.

### Способ 2. Использование Python
```powershell
python -m http.server 8080
```
После запуска перейдите по адресу `http://localhost:8080`.

### Способ 3. Расширение Live Server
В редакторе VS Code или Antigravity откройте файл `index.html` и нажмите «Open with Live Server».

## Управление в игре

### Десктопное управление (Клавиатура и мышь)
* **W, A, S, D**: Перемещение вперед, влево, назад, вправо.
* **Пробел**: Прыжок / всплытие в воде / полет вверх (в режиме Creative).
* **Left Shift**: Приседание / полет вниз (в режиме Creative).
* **Двойное нажатие W / Зажатие RUN**: Спринт (ускоренный бег).
* **Мышь**: Вращение камеры и направление взгляда (требуется клик по экрану для захвата курсора).
* **Левая кнопка мыши (ЛКМ)**: Разрушение блоков / атака мобов.
* **Правая кнопка мыши (ПКМ)**: Установка блока / взаимодействие с верстаком, печью, дверями.
* **1 — 9 / Колесо мыши**: Переключение активного слота панели быстрого доступа (Hotbar).
* **E**: Открытие / закрытие инвентаря и меню крафта.
* **Q / Ctrl+Q**: Выбросить один предмет / выбросить всю стопку из активного слота.
* **Escape**: Выход в меню паузы / освобождение курсора.

### Сенсорное управление (Смартфоны и планшеты)
* **Виртуальный джойстик (слева снизу)**: Направление и скорость перемещения.
* **Область экрана справа**: Проведение пальцем для вращения камеры.
* **Короткий тап по блоку**: Установка блока (эмуляция ПКМ).
* **Удержание пальца на блоке (Hold)**: Разрушение блока (эмуляция ЛКМ с вибрацией).
* **Кнопка JUMP**: Прыжок.
* **Кнопка RUN**: Переключение спринта.
* **Кнопка INV**: Открытие инвентаря.
* **Кнопка ||**: Меню паузы.

## Студия LumiBench

LumiBench Studio позволяет создавать новые блоки и предметы для LumiBox прямо в браузере. Для перехода в студию нажмите кнопку «LumiBench Studio» в главном меню игры или откройте файл `lumiBench/LumiBench.html`.

Возможности студии:
* Создание и редактирование воксельных моделей.
* Попиксельное рисование текстур на гранях кубических моделей.
* Настройка физических свойств блока (прозрачность, твердость, горючесть, светимость).
* Экспорт готового модуля в виде манифеста `.lumibench` или архива `.zip` для подключения в игре.
